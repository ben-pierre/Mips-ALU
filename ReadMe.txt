
# MIPS ALU

A CPRE 381 project implementing a functional MIPS Arithmetic Logic Unit (ALU) in VHDL, capable of executing TI-Nspire code.

## Overview

The project involved designing and implementing an ALU in VHDL as part of CPRE 381. The goal was to create a working hardware implementation capable of supporting the operations needed to run TI-Nspire code.

## Technologies

- **VHDL** — Hardware description and ALU implementation
- **MIPS** — Instruction set architecture
- **CPRE 381** — Computer architecture coursework
